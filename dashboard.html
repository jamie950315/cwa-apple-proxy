回退與 ntfy 通知

翻譯路徑包含 CWA 取資料及本機封包轉換，期限為 3.5 秒。逾時或翻譯錯誤即保留 Apple 原始回應，隨後非同步通知 ntfy.sh/cwa-apple-proxy；相同原因每 5 分鐘最多推送一次，每次錯誤仍寫入本機紀錄。

通知內容包含原因、耗時、程序模式與版本；精確座標、API key 與 Apple 認證資訊留在本機。Pi5 整機離線時需另設外部監測。

iPhone／iPad 設定
裝置連接 Tailscale，以 Safari 取得憑證描述檔，在「設定 → 一般 → VPN 與裝置管理」安裝，再到「設定 → 一般 → 關於本機 → 憑證信任設定」啟用 CWA Weather Bridge Root 完整信任。CA 名稱限制為 weatherkit.apple.com。
Tailscale Exit Node 選 None／無，啟用 Tailscale DNS 與子網路路由，並完成上方管理端的 relay 路由核准；DNS 應維持天氣域名回覆 Pi5。確認憑證信任後，於 Pi5 啟用該裝置：
cd /home/jamie/cwa-weather-proxy
sudo .venv/bin/python bridgectl.py enable 100.123.14.68 --confirm-certificate-trusted
停用該裝置導流：
sudo .venv/bin/python bridgectl.py disable 100.123.14.68
